현재 한계

대부분의 학습 이미지는 통제된 조건에서 촬영됐습니다. 일반 농장·온실의 복잡한 배경, 조명, 여러 장의 잎이 포함된 사진에서의 신뢰도는 검증되지 않았습니다. 유사 이미지에 의한 데이터 누수 가능성도 완전히 배제하지 않았습니다.

화면에 표시되는 분류 확률은 소프트맥스 출력값이며 교정된 신뢰도나 실제 질병 확진을 의미하지 않습니다.
